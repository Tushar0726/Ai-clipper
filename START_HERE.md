# Start a new clipping job (copy-paste this)

Open a new Claude Code session **on this repo** (tushar0726/ai-clipper), then paste this message
and replace the link:

```
Clip this stream: <PASTE LINK HERE>
First run: git fetch origin claude/affectionate-newton-zzkvwl && git checkout claude/affectionate-newton-zzkvwl
Then follow CLAUDE.md exactly (setup_linux.sh, 4K original style, download pages for my iPad, Hinglish).
```

Want a specific stream from a channel instead of a link? Use:

```
Clip <streamer name>'s best <game> stream from Kick. Follow CLAUDE.md.
```

## What happens
1. Setup: about 10-15 minutes the first time in a new session.
2. Download + transcript: about 10-12 minutes per hour of stream.
3. Claude reads the transcript and picks the best moments: about 15-30 minutes.
4. 4K clips: about 5 minutes each, sent to download pages as they finish.

## Good to know
- **Kick and Twitch links work.** YouTube links are blocked on the cloud server.
- Clips are 30-60 seconds, 9:16 vertical 4K, with captions, emojis, zooms and jump cuts. No music.
- Each clip comes with a title, description and hashtags ready to copy.
